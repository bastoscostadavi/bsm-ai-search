# Exploration report template

Unpopulated template. Do not present this file as an executed exploration.

## Question and scope

Record the run ID, parent attempts, exact campaign, search bounds, and candidate revisions.

## Established results

For each result, state the claim, assumptions, approximation level, check status, and evidence paths. Separate computational reproduction from literature claims.

## Calculations and reproduction

Give environment setup, exact commands, dependency versions, expected outputs, precision, and tolerances. Explain any unavailable tools or unexported event categories.

## Failures and unresolved checks

Separate physical obstructions from bounded search failures, execution errors, and missing evidence. Record whether stationarity, boundedness, local stability, and global minimality were each established.

## Handoff and next investigation

Name the specific question, required input revisions, and calculation that should happen next. Include references and limitations on completeness or novelty.
